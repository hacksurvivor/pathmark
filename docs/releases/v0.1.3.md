# Pathmark v0.1.3

Proactive Codex recall.

## What's New

- Codex prompt hooks now search Pathmark before each non-trivial user prompt and inject matching memories as Codex `additionalContext`.
- Prompt-time recall is scoped to the current workspace or session, so unrelated projects are not pulled in just because they share a similar name.
- Current prompts are saved after recall, so Pathmark does not echo the prompt back as if it were prior memory.
- Added `PATHMARK_CODEX_PROACTIVE_RECALL=off` for users who want capture without prompt-time injection.

## Why It Matters

Pathmark memory should not sit idle until the user explicitly asks for it. Codex users now get useful local context proactively while still keeping the visible `recall_memory` MCP tool for audits and cross-harness workflows.

## Verification

- `npm test`
- Codex adapter tests cover proactive prompt recall and the opt-out flag.
