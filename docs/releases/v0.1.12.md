# Pathmark v0.1.12

Pathmark v0.1.12 is the public Registry-compatible patch for the intent-first memory release introduced in v0.1.11.

## Official MCP Registry compatibility

- Shorten the public server description to the Registry's 100-character limit without changing Pathmark's package identity or transport.
- Enforce the Registry description limit during release verification so an invalid tag cannot reach publication again.
- Keep npm, MCP server, citation, CodeMeta, package transport, and Registry versions aligned at v0.1.12.

## Included product capabilities

- Proactive approved-intent recall with a bounded fresh raw-evidence fallback.
- Evidence-backed, approval-gated memory consolidation with exact provenance.
- Conclusion-first memory chat from MCP and the CLI.
- Read-only recall, staleness, duplication, and synthesis-coverage audit metrics.
- A prominent README What's New section and live published-version badge.

See the [v0.1.11 release notes](v0.1.11.md) for the full feature-level detail.

## Verification

- Full TypeScript build, runtime suite, memory-quality evaluation, and ESLint.
- Coverage thresholds and dependency audit.
- npm tarball and release metadata verification.
- Official MCP Registry validation before OIDC authentication or publication.
