# Pathmark v0.1.4

Visible proactive recall for Codex.

## What's New

- Codex prompt-time recall now asks the model to call `mcp__pathmark__recall_memory` when matching memories are injected.
- The visible recall request includes the same search query plus the current workspace or session tag, so the UI card can show the exact `usedMemories` behind the injected context.
- `recall_memory` now accepts optional `tags` for scoped visible recall.
- Added `PATHMARK_CODEX_VISIBLE_RECALL=off` for users who want proactive hidden context without a visible tool-call request.

## Why It Matters

Prompt-time injection makes Pathmark useful automatically. Visible recall makes it auditable. Codex users can see which memory IDs, timestamps, sources, matches, tags, and previews were used without asking manually each time.
