# Pathmark v0.1.15

Pathmark v0.1.15 keeps proactive Codex memory active while making its default presentation quiet and answer-first.

## Quiet proactive recall

- Relevant approved conclusions and bounded in-scope fallback evidence are still injected before Codex answers.
- The default no longer asks Codex to emit a separate raw `recall_memory` tool result into the conversation.
- Set `PATHMARK_CODEX_VISIBLE_RECALL=on` to restore the explicit recall trace for debugging, audits, or memory-quality review.
- The visible mode continues to use the exact pre-capture record IDs, so its audit trail cannot confuse the current prompt with previously recalled memory.

## Dependency security

- Update transitive `fast-uri` from 3.1.5 to 3.1.7, above the patched threshold for four high-severity advisories.
- Update transitive `qs` from 6.15.3 to 6.16.0, the patched release for its open medium-severity advisory.

## Verification

- Regression coverage proves the default injects relevant memory without a visible recall instruction.
- Existing visible-recall tests run with the explicit opt-in and continue to verify exact IDs and bounded payloads.
- Full TypeScript build, runtime suite, memory-quality evaluation, ESLint, and coverage thresholds.
- Release metadata, package contents, installed-package canary, and live Codex adapter status are checked before public promotion.
