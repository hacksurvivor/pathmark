# Pathmark v0.1.7

Pathmark v0.1.7 hardens the npm release pipeline and fixes the findings discovered by the new CodeQL gate.

## Security and release hardening

- Pin every GitHub Action to an immutable commit SHA.
- Require Node 22, Node 24, dependency-review, and CodeQL checks before merging.
- Add npm auditing, Dependabot security updates, OpenSSF Scorecard analysis, CodeQL, secret scanning, push protection, and private vulnerability reporting.
- Publish npm releases with explicit SLSA provenance.
- Remove owner bypass access from `main` and protect existing release tags from updates and deletion.

## Fixes

- Replace a potentially inefficient Node command-detection regular expression with bounded token parsing.
- Use an exact URL assertion in the redaction regression test.
- Add regression coverage for Node flags and long adversarial command input.

All runtime tests, lint, dependency auditing, dependency review, and CodeQL checks pass with zero open CodeQL alerts.
