# Pathmark v0.1.14

Pathmark v0.1.14 keeps approved conclusions available when callers explicitly scope conversational recall to the workspace, project, or namespace recorded on their supporting evidence.

## Effective conclusion scope

- Treat a conclusion's direct tags as authoritative.
- When a requested `workspace:`, `project:`, or `namespace:` tag is absent from a conclusion, inherit it only when every cited evidence record is a memory carrying that exact tag.
- Keep non-scope tags exact; session tags are never inherited.
- Reject inheritance when evidence is missing, cites another conclusion, belongs to a foreign scope, or mixes scopes.

## Reliable and bounded retrieval

- Resolve effective scope before applying the final result limit, so unrelated global conclusions cannot crowd out a valid inherited match.
- Batch evidence lookups and reuse them within each query.
- Preserve conclusion-first ranking, extractive answers, provenance, and recall feedback behavior.

## Verification

- Regression coverage for direct, inherited, foreign, mixed, missing, and wrong-kind evidence cases.
- More than 50 competing foreign conclusions to prove inherited matches survive the global search cap.
- Explicit `kind: conclusion` coverage for project and namespace inheritance.
- Full TypeScript build, runtime suite, memory-quality evaluation, ESLint, and coverage thresholds.
- Live-store-copy chat check before public promotion.
