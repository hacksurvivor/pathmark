# Pathmark v0.1.8

Pathmark v0.1.8 makes transparent recall and Codex activity provenance production-ready while keeping tool-output text private by default.

## Recall correctness and retrieval quality

- Pin visible recall to the exact pre-capture memory IDs so the current prompt cannot replace the evidence originally injected.
- Remove the redundant full-record copy from automatic visible recall.
- Add multi-concept relevance thresholds, conservative search aliases, English/Russian stop-word handling, and near-duplicate suppression.
- Prefer project and namespace matches for named queries and add a global fallback for explicit cross-project recall.
- Treat global prompt recall as a true fallback: when workspace/session results are relevant, do not fill remaining slots with other projects.
- Exclude legacy transport envelopes and assistant progress updates from session-start and proactive relevance selection.
- Rebuild the derived SQLite index in `memory.index.v4.sqlite` for the new search aliases, allowing old and new MCP processes to coexist during a rolling restart.

## Session activity provenance

- Add the `session_trace` MCP tool for a chronological prompt, injected-memory, tool-result, and answer trail.
- Capture command/input previews and hashes, status, exit code, duration, output hash, and changed files from successful and failed tool hooks.
- Keep output text private by default. `PATHMARK_CODEX_CAPTURE_TOOL_OUTPUTS=on` opts into a redacted preview capped at 2,000 characters.
- Expire activity after 30 days and physically cap it at 5,000 records by default, with configurable overrides.
- Preserve structured activity through export/import and prevent compaction from merging separate events.
- Capture Codex final answers instead of intermediate commentary and migrate existing transcript cursors without duplicating prior user or final-answer turns.
- Unwrap Codex file/annotation/diff transport envelopes to retain the actual request, skip injected plugin/goal/subagent payloads, and soft-delete exact legacy commentary matches during migration.

## Verification

- Add a five-query retrieval acceptance corpus based on the real failure modes discovered in production memory.
- Add regression coverage for output privacy, retention, invalid-line preservation, cross-project exact recall, failed tools, adversarial tokenizer keys, parser migration, commentary suppression, and live process-boundary capture.
- Verify Node 22/24-compatible build, runtime tests, lint, coverage thresholds, dependency audit, package contents, upgrade migration, and live Codex installation before release.
