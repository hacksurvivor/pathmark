# Pathmark v0.1.13

Pathmark v0.1.13 makes proactive memory more precise, conversational, and measurable without promoting raw session history into hidden truth.

## Multi-intent proactive recall

- Split compound questions into distinct intents and retrieve an approved conclusion for each topic before filling remaining results.
- Use the same intent-aware selection in MCP chat, CLI chat, and proactive Codex prompt recall.
- Preserve exact memory provenance for every returned conclusion.

## Safer memory boundaries

- Require explicit scope or `kind: memory` before chat can fall back to raw evidence.
- Exclude internal prompts, response annotations, harness instructions, unsafe records, and quarantined captures from proactive recall and consolidation.
- Keep explicit raw-memory search available for archive inspection.

## Conversational answers and feedback

- Return safe extractive answers from approved conclusions in the default client synthesis mode.
- Return an exact `recallId` from `chat` and `ask_memory` when matched recall activity is recorded; abstentions and read-only stores return `null`.
- Add MCP `rate_recall` and CLI `pathmark feedback` for relevant and irrelevant memory labels.
- Redact feedback notes and reject labels for records that were not part of the referenced recall.

## Measurable consolidation

- Report labeled precision and label coverage only when explicit relevance feedback exists.
- Separate consolidation-eligible evidence from intentionally excluded raw records in audits.
- Add stable `cursor`, `nextCursor`, and `remainingAfterBatch` fields for progressive bounded consolidation.
- Keep all generated conclusions pending until explicitly approved.

## Verification

- Full TypeScript build, runtime suite, memory-quality evaluation, and ESLint.
- 20 positive retrieval cases and 20 abstention cases.
- Coverage thresholds, dependency audit, and npm tarball validation.
- Installed-package canary and live-store-copy retrieval checks before public promotion.
