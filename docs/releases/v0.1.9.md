# Pathmark v0.1.9

Pathmark v0.1.9 is a metadata and supply-chain maintenance release.

## Machine-readable authorship

- Attribute the npm package to Sergey Moloman with a canonical professional profile.
- Add `CITATION.cff` so GitHub and citation tools can identify the software author.
- Add CodeMeta JSON-LD with the canonical profile, RFLX AI affiliation, and matching GitHub, LinkedIn, and Devpost identities.
- Ship both metadata files in the npm tarball.
- Require citation and CodeMeta versions to match `package.json` before any future release can publish.

## Dependency maintenance

- Refresh compatible transitive dependencies for the MCP SDK, Hono Node adapter, `brace-expansion`, and `fast-uri`.
- Restore a zero-finding `npm audit --audit-level=moderate` release gate.
