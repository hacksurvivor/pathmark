# Pathmark v0.1.10

Pathmark v0.1.10 prepares the package for verifiable publication in the
official Model Context Protocol Registry.

## Registry metadata

- Add the stable Registry name `io.github.hacksurvivor/pathmark`.
- Ship a schema-linked `server.json` describing the npm package and stdio
  transport.
- Include the Registry name in `package.json` so the official Registry can
  verify npm package ownership.
- Require package, MCP server, citation, CodeMeta, and Registry versions to
  match before release.
- Align the human-readable and CodeMeta author records with Sergey Moloman's
  public role as a B2B AI integration specialist and private AI contractor.

## Controlled publication

- Add a manual GitHub OIDC workflow for official MCP Registry publication.
- Require an exact confirmation phrase and an already-published npm version.
- Validate the metadata with the Registry API before publishing.
- Pin the publisher binary and verify its SHA-256 digest.

## Verification

- Build and runtime test suite on Node.js 22 and 24.
- ESLint and coverage thresholds.
- Dependency review and CodeQL.
- Release metadata and npm tarball verification.
