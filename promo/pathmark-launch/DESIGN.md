# Pathmark promo visual identity

## Style Prompt

A technical-cinematic launch film that feels like a premium developer tool opening a dark control room: crisp editorial typography, precise terminal details, memory records moving as luminous signals, and confident directional transitions. The visual argument is a persistent memory trail that crosses agent boundaries without leaving the user's machine.

## Brand Strategy

- Category: local-first developer infrastructure and MCP memory tooling.
- Audience: developers who switch between AI coding agents and dislike rebuilding context.
- Promise: switch agents without losing the decisions and rules behind the work.
- Core metaphor: a visible memory trail routed through a local hub.
- Trust posture: inspectable, restrained, and evidence-led.

## Colors

- `#071018` — ink-blue canvas and shared scene background
- `#EAF3F5` — cool white primary text
- `#9FB0B8` — secondary text and metadata
- `#39E6D0` — Pathmark teal for memory flow, recall, and primary action
- `#F5A623` — amber for decisions, agent handoffs, and selective emphasis

## Typography

- `Bricolage Grotesque` — expressive launch headlines at 800 weight
- `IBM Plex Mono` — body copy, commands, identifiers, and technical labels at 300-600 weights

## Signature Motif

Memory records leave a thin luminous trail as they move between tool frames. The trail persists just long enough to communicate continuity, then resolves into the Pathmark hub. Small IDs, tags, crosshairs, and page-like labels reward close viewing without pretending to be a complete product UI.

## Motion

- Precise, confident entrances with short overlaps and varied direction.
- Memory records travel as routed signals; ambient motion stays slow and understated.
- Primary transition: directional push. Accent transition: brief overexposure at the Pathmark reveal. Outro: gentle color dip.
- The first motion in each scene establishes hierarchy; no decorative motion competes with the product claim.

## What NOT to Do

- No purple/blue SaaS gradients, generic glass-card grids, or rainbow neon.
- No fake UI claims, fake adoption numbers, stars, or performance statistics.
- No dense paragraphs; every frame must scan in under two seconds.
- No glitch overload, hacker clichés, matrix rain, or anonymous hooded imagery.
- No unverified cloud, encryption, sync, or privacy guarantees beyond the documented local JSONL default.
